\# ДЗ 1: Верстка сервиса вопросов-ответов



\## Как открыть проект

Это статический HTML-проект. Для просмотра просто открой файл `public/index.html` в любом современном браузере (двойной клик по файлу или Правая кнопка мыши → Open with → Browser).



\## Структура страниц 

\- `public/index.html` — Главная страница (список вопросов)

\- `public/question\_detail.html` — Страница конкретного вопроса

\- `public/ask.html` — Страница создания нового вопроса

\- `public/login.html` — Страница входа

\- `public/signup.html` — Страница регистрации

\- `public/tag.html` — Страница вопросов по тегу

\- `public/profile.html` — Страница настройки профиля

\- `public/base.html` — Базовый шаблон (не открывается напрямую)



\## Статика

CSS находится в папке `public/static/` (Bootstrap работает через CDN)
